# Тренажёр по общей медицинской микробиологии

Одностраничный HTML-тренажёр. Для публикации через GitHub Pages:

1. Загрузите `index.html`, `.nojekyll` и `README.md` в корень репозитория.
2. Откройте Settings → Pages.
3. В разделе Build and deployment выберите Deploy from a branch.
4. Выберите ветку `main` и папку `/(root)`, затем нажмите Save.

После успешной публикации сайт будет доступен по адресу:
https://artempetrusevich.github.io/microbiology-trainer/
