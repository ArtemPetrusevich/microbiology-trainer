# Тренажёр по общей медицинской микробиологии

Одностраничный HTML-тренажёр (**v2.6 — полный курс**). Контент собран по официальному перечню вопросов и задач от 12.01.26 и учебному пособию по общей микробиологии (СЗГМУ).

## Что внутри v2.6

- **Модули 1.1–1.5** — морфология, структура клетки, клеточная стенка, окраски, микроскопия
- **Модули 2.1–2.5** — физиология, питание, культивирование, генетика и молекулярная диагностика
- **Модуль 3** — бактериофаги
- **Модуль 4** — деконтаминация и антимикробная терапия
- **Модуль 5** — инфекция, патогенность, токсины
- **Модуль 6** — иммунодиагностика и ИБП
- **Модуль 7** — микробиота, микозы, новые технологии
- **Модуль 8** — общая вирусология
- **Модуль 9** — навигатор по 58 темам вопроса №2 (частная микробиология), 58 справок
- **Контрольный тест** — 20 вопросов самоконтроля из пособия
- **149 ситуационных задач** из официального перечня: поиск, фильтры «непрорешанные / сложные / прорешанные», самопроверка
- **Итоговый прогон** — экзаменационный билет: случайный вопрос №1, тема вопроса №2 (со ссылкой на справку) и 3 ситуационные задачи
- **Микропрактикум** — 24 препарата, включая 15 контрольных микрофотографий из пособия с официальными описаниями (морфология, окраска, метод микроскопии)
- Экспорт / импорт прогресса (JSON) с автоматическим бэкапом перед импортом
- Весь прогресс хранится локально в браузере; микрофотографии встроены в файл и работают без интернета

Итого: 18 модулей, 323 вопроса тестов, 149 задач, 24 микропрепарата.
