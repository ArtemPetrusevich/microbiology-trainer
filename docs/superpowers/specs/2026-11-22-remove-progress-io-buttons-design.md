# Удаление кнопок импорта и экспорта прогресса

## Цель

Убрать из карточки «Мой прогресс» кнопки «Экспорт прогресса (JSON)» и «Импорт прогресса», не меняя остальное поведение тренажёра.

## Изменение

- В `build/ui_patch.js` удалить строку интерфейса с классом `io-row`, содержащую обе кнопки.
- Из пояснения внизу главного экрана удалить предложение «Экспорт прогресса — в карточке «Мой прогресс» выше.», поскольку оно станет неверным.
- Заново собрать `repo/index.html` через существующий `build_v26.py`.
- Сохранить функции `exportProgress()` и `importProgress()`, их стили и остальные файлы без изменений.

## Проверка

- Сборка завершается успешно.
- В собранном `index.html` отсутствуют обе кнопки и удалённое пояснение.
- Блок статистики и сообщение о локальном сохранении прогресса остаются на месте.
- Изменения ограничены исходным UI-патчем, новой сборкой и этой спецификацией.
